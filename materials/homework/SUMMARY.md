# JS · Урок 2 · Типы данных — шпаргалка

## Пять простых типов (primitives)
| Тип | Пример | typeof |
|---|---|---|
| string — строка | `"Айдай"`, `'Бишкек'`, `"15"`, `""` | `"string"` |
| number — число | `15`, `4.8`, `-5`, `NaN` | `"number"` |
| boolean — логический | `true`, `false` | `"boolean"` |
| undefined — не задано | `let phone;` | `"undefined"` |
| null — пусто специально | `let avatar = null;` | `"object"` ⚠ |

## typeof
- `typeof x` — тип значения в виде строки: `typeof 15` → `"number"`.
- Ловушка: `typeof null` → `"object"` (историческая ошибка JS).

## Строки и числа
- Кавычки любые, но одинаковые: `"…"`, `'…'`, `` `…` ``.
- Цифры в кавычках — строка: `"15"`.
- Дробь — через точку: `4.8`.
- `NaN` — «не число», тип `number`. `0.1 + 0.2` ≠ `0.3` ровно.

## Само приводится (type coercion)
- `+` со строкой склеивает: `"5" + 2` → `"52"`.
- `-` `*` `/` делают числа: `"5" - 2` → `3`, `"5" * "2"` → `10`.
- Слева направо: `"5" + 2 + 3` → `"523"`, `2 + 3 + "5"` → `"55"`.

## Приводим сами (type conversion)
- `Number("42")` → `42`, `Number("")` → `0`, `Number("12px")` → `NaN`.
- `String(42)` → `"42"`.
- `Boolean(x)`: ложь (falsy) только у `0`, `""`, `null`, `undefined`, `NaN`, `false`. Всё остальное — `true`.

## Исключения и ловушки
1. `"15"` — строка. Данные из форм всегда приходят строками.
2. `"10" + 5` → `"105"`. Сначала `Number()`, потом складываем.
3. `typeof null` → `"object"`.
4. `typeof NaN` → `"number"`.
5. `Number("")` → `0`, а `Number("abc")` → `NaN`.
6. `Number("  7  ")` → `7` (пробелы по краям не мешают), `Number("12px")` → `NaN`.
7. `Number(null)` → `0`, а `Number(undefined)` → `NaN`.
8. `Boolean("0")` и `Boolean("false")` → `true`: непустая строка всегда истина.
9. Дробь через точку: `4.8`. `4,8` — ошибка.
10. `typeof` с опечаткой в имени не ругается — вернёт `"undefined"`.

## Словарь разработчика
| Термин | English | Как говорят | Пример |
|---|---|---|---|
| Тип данных | data type | «тип» | `typeof 42` |
| Примитив | primitive | «простой тип» | `"текст"`, `7`, `true` |
| Строка | string | «стринга» | `"Айдай"` |
| Число | number | «намбер» | `4.8` |
| Логический тип | boolean | «булеан», «буль» | `true` |
| Не определено | undefined | «андефайнд» | `let phone;` |
| Пустое значение | null | «нал» | `let avatar = null;` |
| Склейка строк | concatenation | «конкатенация» | `"a" + "b"` |
| Неявное приведение | type coercion | «само привелось» | `"5" - 2` |
| Явное приведение | type conversion | «привести к числу» | `Number("42")` |
| Не число | NaN | «нан» | `Number("abc")` |
| Ложные значения | falsy | «фолси» | `Boolean(0)` |
| Литерал | literal | «значение прямо в коде» | `"Бишкек"` |
