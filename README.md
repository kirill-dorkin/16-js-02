## Слайды (24)
Разминка (const) → что такое тип → пять типов → string → number → boolean / undefined / null → typeof по шагам → игра «Угадай тип» → ловушка null → строка + число по шагам → правила приведения → Number / String / Boolean → лаборатория приведения → отладка → практика вместе → самостоятельная → словарь → шпаргалка (понятия + исключения) → домашка.

Клавиши: ← → — слайды, Пробел / ↓ — шаг демо, G — оглавление, N — заметки, T — тема, F — экран.
